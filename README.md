Solmar Bay is a complete original top-down 2D open-world crime game: drive and steal cars across an 8x8-block city, outrun the police through a 5-star wanted system, take on 4 story missions, fight on foot, and track it all on a live minimap HUD. Pure static files, no network requests, keyboard and mouse.

## Run it

```sh
python3 -m http.server 8000 --directory game
```
Then open http://localhost:8000/index.html in desktop Chrome. (Any static file server works; game/index.html is the entry point.)
